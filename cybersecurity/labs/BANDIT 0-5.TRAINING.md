Bandit can be accessed through a windows powershell, linux terminal and a mac terminal.
The command to input is :
  ssh bandit0@bandit.labs.overthewire.org -p2220
  Decoding the command
  ssh - this means secure shell protocol connect to a remote system.
  bandit0 - this is the username
  @ - separates user name from the server
  bandit.labs.overthewire.org - this is the server address
  -p 2220 - This is the port to be used to connect through
